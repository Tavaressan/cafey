Caféy · protótipo de interface

Cinco telas do app

Implementação em HTML e CSS do projeto de design Caféy coffee machine control UI. Cada tela é responsiva: barra de abas no celular, trilho de ícones no tablet e barra lateral no desktop. Redimensione a janela para atravessar os três pontos de quebra.

InícioEstado da máquina, um controle manual, o próximo preparohome.html AgendamentosLista e editor — “café pronto às”, não “ligar às”schedule.html RitmoFrases primeiro, gráficos depoisrhythm.html CuidadosContado em preparos, dito em palavras simplescare.html BaseO aparelho, no fundo escurobase.html

As telas usam dados de exemplo. Nada aqui conversa com o backend ou com a base — o protótipo existe para fixar a linguagem visual antes do cliente Kotlin Multiplatform.
